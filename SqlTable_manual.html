SqlTable Class Manual

Purpose: simple table access and repository-style convenience methods built on top of SqlQuery.

Design: SqlTable reads one in-memory table. Use Query for filtering, sorting, joins, grouping, and output. SQL below is conceptual because the library does not parse SQL text.

Overview and row indexing

The source first row is the header. Public row indexes are 1-based data-row indexes; the header is not counted. For Employees!A1:E13, row 1 is Ivan and row 12 is Viktor.

Dim employees As SqlTable
Set employees = New SqlTable
Set employees = employees.OpenRange(Worksheets("Employees").Range("A1:E13"))

Query

Public Function Query() As SqlQuery

Creates a new SqlQuery loaded with the table data. The table remains unchanged.

Dim query As SqlQuery
Set query = employees.Query()
Set query = query.Where("Department", "=", "IT")
query.WriteToRange Worksheets("Results").Range("A1")

SQL: SELECT * FROM Employees WHERE Department = 'IT'.

Relationship to SqlQuery

SqlTable is for direct table access. SqlQuery performs joins, filtering, projection, grouping, ordering, paging, and writes result sets to Excel. The recommended flow is:

SqlTable → Query() → SqlQuery → ToArray()/WriteToRange()

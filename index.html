Excel VBA SQL Emulator Class

A lightweight, in-memory SQL-like query engine and table-access layer for standard Excel VBA.

What is this project?

This project provides two pure-VBA class modules for working with tabular Excel data in memory. SqlQuery provides a fluent query API, while SqlTable provides convenient direct table access and lookup methods.

The library does not parse SQL text. The SQL shown in the documentation is a conceptual equivalent of the executable VBA API.

Quick start

Import SqlQuery.cls into an Excel VBA project, then use the fluent API:

Dim query As SqlQuery
Set query = New SqlQuery
Set query = query.LoadRange( _
    ThisWorkbook.Worksheets("Employees").Range("A1:E13"))
Set query = query.SelectColumns("Name", "Salary")
Set query = query.Where("Department", "=", "IT")
Set query = query.OrderBy("Salary", "DESC")
query.WriteToRange ThisWorkbook.Worksheets("Results").Range("A1")

Supported operations

Querying

SELECT-style projection, aliases, AND/OR/NOT, grouped predicates, LIKE, IN, NULL predicates, and typed conversion.

Data shaping

DISTINCT, computed columns, multi-column ordering, paging, composite JOIN keys, duplicate-column aliases, and chained JOINs.

Analytics

GROUP BY, aggregate aliases, execution-order guarantees, COUNT, SUM, AVG, MIN, and MAX.

Safe writes

SqlMutation snapshot mutations, commit validation, rollback, atomic restore, and commit logging.

Pure VBA

No external DLLs, ActiveX controls, or mandatory third-party references.

Примерите използват Employees!A1:E13 и текущия клас SqlMutation.

Подготовка: импортирайте SqlMutation.cls като Class Module. Промените се записват само при Commit.

1. OpenRange

Dim mutation As SqlMutation
Set mutation = New SqlMutation
Set mutation = mutation.OpenRange(ThisWorkbook.Worksheets("Employees").Range("A1:E13"))
Оригиналният диапазон е отворен, но още не е променен.

2. AutoRange

Dim mutation As SqlMutation
Set mutation = New SqlMutation
Set mutation = mutation.AutoRange("Employees")
Debug.Print mutation.RowsAffected

Преди mutation операцията RowsAffected е 0.

3. INSERT

Dim mutation As SqlMutation
Dim values As Object
Set mutation = New SqlMutation
Set mutation = mutation.AutoRange("Employees")
Set values = CreateObject("Scripting.Dictionary")
values("EmployeeId") = 13
values("Name") = "Nikolay"
values("Department") = "IT"
values("Salary") = 3100
values("Active") = True
mutation.Insert values
Debug.Print mutation.RowsAffected       ' 1
mutation.Commit
EmployeeIdNameDepartmentSalaryActive
13NikolayIT3100True

4. UPDATE

Dim values As Object
Set values = CreateObject("Scripting.Dictionary")
values("Salary") = 3600
mutation.UpdateWhere "Name", "=", "Ivan", values
Debug.Print mutation.RowsAffected       ' 2
mutation.Commit
И двата реда с Name = Ivan са променени.

5. UPDATE с IS NULL

Set values = CreateObject("Scripting.Dictionary")
values("Department") = "Unknown"
mutation.UpdateWhere "Department", "IS NULL", Empty, values
Debug.Print mutation.RowsAffected
mutation.Commit
Редът с празен Department е променен.

6. UPDATE с LIKE

Set values = CreateObject("Scripting.Dictionary")
values("Active") = False
mutation.UpdateWhere "Name", "LIKE", "E*", values
Debug.Print mutation.RowsAffected
mutation.Commit
Elena, Emilia и Emil са маркирани като неактивни.

7. DELETE

Dim mutation As SqlMutation
Set mutation = New SqlMutation
Set mutation = mutation.AutoRange("Employees")
mutation.DeleteWhere "Department", "=", "Legal"
Debug.Print mutation.RowsAffected       ' 1
mutation.Commit
Anna е премахната от in-memory snapshot-а и след Commit worksheet row-ът се изтрива физически, без остатъчен ред.

8. TRUNCATE

Set mutation = New SqlMutation
Set mutation = mutation.AutoRange("Employees")
mutation.Truncate True
Debug.Print mutation.RowsAffected
mutation.Commit
Всички data rows са премахнати, header row е запазен.

9. Rollback

Set values = CreateObject("Scripting.Dictionary")
values("Salary") = 9999
mutation.UpdateWhere "Name", "=", "Ivan", values
mutation.Rollback
' Worksheet-ът не е променен.
Rollback презарежда worksheet range-а и изхвърля in-memory промените.

10. Mutation builder

Dim values As Object
Set values = CreateObject("Scripting.Dictionary")
values("Salary") = 3600
mutation.Where("Department", "=", "IT").AndWhere "Name", "=", "Ivan"
mutation.NotWhere "Name", "=", "Anna"
Debug.Print mutation.MatchedCount
mutation.Update values
mutation.Commit
Builder-ът комбинира условията с AND.

11. OR, NOT, groups и Preview

mutation.BeginGroup
mutation.Where "Department", "=", "IT"
mutation.OrWhere "Department", "=", "HR"
mutation.EndGroup
mutation.AndWhere "Active", "=", True
Debug.Print mutation.Count
result = mutation.Preview()
Preview връща matched rows с header row, без да променя worksheet-а.

12. Typed mutation filters

mutation.SetConversionPolicy "IGNORE"`r`nmutation.WhereTyped "Salary", ">", "3000", "DOUBLE"`r`nDebug.Print mutation.MatchedCount`r`nmutation.Delete
Невалидните числови стойности се игнорират при policy IGNORE.
`r`n

13. INSERT policies

mutation.SetInsertPolicy "STRICT"`r`nmutation.RequireInsertColumns "EmployeeId", "Name"`r`nvalues("EmployeeId") = 13`r`nvalues("Name") = "Nikolay"`r`nmutation.Insert values
STRICT отхвърля unknown keys и липсващи required columns. По подразбиране policy е LENIENT.
`r`n

11. Безопасен commit workflow

mutation.UpdateWhere "Department", "=", "IT", values
If mutation.RowsAffected > 0 And mutation.RowsAffected <= 10 Then
    mutation.Commit
Else
    mutation.Rollback
End If

Проверявайте RowsAffected преди Commit, особено при UPDATE.

Current mutation safety examples

Validate before commit

mutation.UpdateWhere "Department", "=", "IT", values
If mutation.RowsAffected > 0 And mutation.RowsAffected <= 10 Then
    mutation.Commit
Else
    mutation.Rollback

On Error GoTo CommitFailed
mutation.Commit

log = mutation.GetCommitLog()

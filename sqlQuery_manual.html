SqlQuery Class Manual

Purpose: fluent, in-memory SQL-like querying for standard Excel VBA.

Important: SqlQuery does not parse SQL text. SQL shown in this manual is a conceptual equivalent; executable code is VBA.

Overview

The first source row is always the header row. The current workbook uses Employees!A1:E13, Departments!A1:D5, and Results!A1.

Dim query As SqlQuery, result As Variant
Set query = New SqlQuery
Set query = query.LoadRange(Worksheets("Employees").Range("A1:E13"))
Set query = query.Where("Department", "=", "IT")
Set query = query.OrderBy("Salary", "DESC")
result = query.ToArray()

InnerJoin

Public Function InnerJoin(rightSource, leftField, rightField, [keyType], [rightAlias]) As SqlQuery

Keeps only left rows with a matching right key. A right source may be a Range or 2D array.

departments = Worksheets("Departments").Range("A1:D5").Value2
Set query = query.InnerJoin(departments, "Department", "Department", "TEXT")
Set query = query.SelectColumns("Name", "Manager")

SQL: INNER JOIN Departments d ON e.Department = d.Department.

Back to contents

LeftJoin

Public Function LeftJoin(rightSource, leftField, rightField, [keyType], [rightAlias]) As SqlQuery

Keeps every left row and fills unmatched right columns with Null.

Set query = query.LeftJoin(Worksheets("Departments").Range("A1:D5"), _

Execution order

JOIN → WHERE → GROUP BY/aggregates → projection → DISTINCT → ORDER BY → LIMIT/OFFSET. Query state is mutable; create a new object for an independent query.
